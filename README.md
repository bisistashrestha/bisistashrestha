## 🚀 Projects

### 🏦 Neeyam — NRB Compliance Copilot
**AI-powered compliance assistance | Pilot**

Working on Neeyam, a compliance copilot designed to help users navigate Nepal Rastra Bank (NRB) regulatory documents and find relevant information through natural-language questions.

- Building a conversational interface for compliance-related queries.
- Focused on document retrieval, evidence-backed answers, and verifiable citations.
- Exploring bilingual document processing and retrieval across English and Nepali regulatory PDFs.
- Working toward more reliable responses by grounding answers in source documents.

*Current focus: Improving document coverage, OCR quality, bilingual retrieval, and answer reliability.*

### 🏨 [Yama Kaze — Resort Booking Web App](https://github.com/bisistashrestha/Hotel-Resort-Booking) · [Live Demo](https://hotel-resort-booking-66l2.vercel.app)

A full-stack resort booking application built during an internship at [CloudOnHire](https://github.com/CloudOnHire).

- Email-based authentication using JWTs stored in HttpOnly cookies.
- Room availability filtering based on check-in and check-out dates.
- Automatic reservation price calculation.
- Trip history and cancellation rules that prevent cancellations on or after check-in.
- Swagger UI and OpenAPI schema for API exploration.
- Django Admin for backend management.

**Stack:** `Django REST Framework` · `PostgreSQL` · `Next.js` · `Tailwind CSS` · `Render` · `Vercel`

### 🧠 [Albert Einstein Chatbot](https://github.com/bisistashrestha/Albert-Einstein-Chat-Bot) · [Watch Demo](https://youtu.be/QcEt5xwcRi4)

An AI chatbot that answers questions about physics, mathematics, and philosophy in a conversational style inspired by Albert Einstein.

- Uses Gemini 2.5 Flash through LangChain.
- Maintains context across multiple turns using recent conversation history.
- Features a minimal Gradio interface with custom avatars and a clear-chat option.

**Stack:** `Python` · `LangChain` · `Google Gemini 2.5 Flash` · `Gradio`

### 🤖 [Todoist Task Manager Agent](https://github.com/bisistashrestha/Todoist-Task-Manager-Agent)

A conversational AI agent for managing Todoist tasks using natural language.

- Uses LangChain AgentExecutor to orchestrate tools that interact with the Todoist API.
- Supports conversational task management and task retrieval.
- Maintains conversation history for contextual interactions.
- Uses Gemini 2.5 Flash for natural-language understanding.

**Stack:** `Python` · `LangChain` · `Google Gemini 2.5 Flash` · `Todoist API`

### 🍅 [Pomodoro Tools App](https://github.com/bisistashrestha/Pomodoro-Tools-App) · [Watch Demo](https://youtu.be/JJSbInN03TY)

A desktop productivity application combining a Pomodoro timer, task manager, and personal notepad.

- Configurable focus and break cycles with pause, resume, and automatic transitions.
- Task management with add, edit, and delete functionality.
- Per-user tasks and notes stored locally.
- Session counter and time-based greetings.

**Stack:** `Python` · `CustomTkinter` · `Local Storage`
